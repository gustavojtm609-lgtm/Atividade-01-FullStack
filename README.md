# Portfólio - Gustavo Junio Tarifa de Moraes

Portfólio pessoal desenvolvido somente com HTML5 e CSS3.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio-gustavo`.
3. Clique duas vezes em `index.html`.

Não é necessário instalar Node.js, executar `npm install` ou iniciar servidor.

## Páginas

- `index.html`: apresentação, tecnologias, formação, experiência, projeto e contato.
- `projeto-despesas.html`: página própria do projeto Full Stack.
- `desenhos.html`: galeria com 19 desenhos.
- `blog.html`: índice dos miniartigos.
- `artigo-fullstack.html`: artigo sobre comunicação entre frontend, backend e banco.
- `artigo-criatividade.html`: artigo sobre desenho e programação.
- `documentos/curriculo-gustavo.pdf`: currículo para download sem CPF, endereço ou outros dados sensíveis.

## Tecnologias do portfólio

- HTML5
- CSS3
- Sem JavaScript
- Sem frameworks

## Observação

O projeto de despesas apresentado no portfólio é Full Stack. O site de portfólio, por escolha da atividade, utiliza apenas HTML e CSS.
