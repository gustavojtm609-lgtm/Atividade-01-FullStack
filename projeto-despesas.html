Visão geral

O sistema tem como objetivo facilitar o registro e o acompanhamento de gastos. O usuário pode cadastrar despesas e organizar as informações em uma interface centralizada.

Participação: 100%Projeto acadêmicoFull Stack

Tecnologias do projeto

HTMLCSSJavaScriptReactNode.jsExpressMySQLSequelize

Principais funcionalidades

  • Cadastro de despesas.
  • Listagem e organização dos registros.
  • Integração entre frontend e API.
  • Armazenamento das informações no MySQL.
  • Estrutura preparada para categorias e indicadores.
